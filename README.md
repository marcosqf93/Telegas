# Tele Gás

Site oficial da Tele Gás com foco em pedidos, SEO local e conversão.

## Executar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Variáveis de ambiente

- `NEXT_PUBLIC_GA4_ID`
- `NEXT_PUBLIC_GTM_ID`
- `NEXT_PUBLIC_META_PIXEL_ID`
- `NEXT_PUBLIC_GSC_VERIFICATION`

## Editar conteúdo

- Produtos, preços, telefones, horários, unidades e FAQ: `src/lib/site-data.ts`
- Fluxo de pedido: `src/components/order-wizard.tsx`
- Promoção Chama Premiada: páginas em `src/app/chama-premiada` e `src/lib/site-data.ts`

## Pendências para o cliente

- Logotipo oficial
- Fotos reais da equipe, veículos e unidades
- Preços por cidade
- Telefones e WhatsApp reais por unidade
- Endereços e horários confirmados
- Conteúdo oficial da promoção
- Avaliações reais do Google
- CNPJ
